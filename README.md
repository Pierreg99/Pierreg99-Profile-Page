## Architecture

```mermaid
flowchart LR
    A[Public GitHub snapshot] --> B[Reviewed project data]
    B --> C[Static portfolio build]
    D[Local visual assets] --> C
    E[DE / EN translations] --> C
    C --> F[Lint, unit tests and links]
    F --> G[Desktop, mobile and accessibility]
    G --> H[Reviewable site artifact]
    H --> I[GitHub Pages via main]
```

**Static first:** Modules in `src/` generate static HTML, CSS and JavaScript. The versioned snapshot drives the public inventory; the browser does not require live GitHub API access. The workflow validates pull requests and only deploys from `main`.

```text
src/
  components/      Accessible cards, navigation and technology atlas
  data/            Reviewed descriptions, metadata and translations
  pages/           Home, galleries, research and documentation
  client/          Optional filters, language and motion behavior
  styles/          Responsive CRYO design system
assets/
  technology/      Twelve original technology icons
  animations/      Versioned source GIFs
  projects/        Public project imagery
  sync/            Versioned public metadata snapshot
scripts/           Build, asset preparation and verification
tests/             Node, Python and Playwright checks
.github/workflows/ Validation and GitHub Pages publication
```

## Quickstart

**Requirements / Voraussetzungen:** Node.js 22+, npm 10+, Python 3.12+ and `ffmpeg`.

```bash
git clone https://github.com/Pierreg99/Pierreg99-Profile-Page.git
cd Pierreg99-Profile-Page
npm ci
npm run dev
```

Local server / Lokaler Server: **http://localhost:4173**.

```bash
npm run check
npx playwright install --with-deps chromium
npm run test:browser
npm run preview
```

`npm run check` runs source linting, unit checks, production build, link validation and offline metadata integrity checks. `npm run test:browser` exercises the desktop/mobile frontend and accessibility. `npm run sync` refreshes public snapshots deliberately and updates the inventory block below.

## Validation

| Gate | Verification | Purpose |
| --- | --- | --- |
| Source style | `npm run lint` | ESLint and Prettier |
| Unit checks | `npm test` | Node.js and Python |
| Static build | `npm run build` | Deployable HTML and optimized assets |
| Sources and links | `npm run validate` | Local references and public snapshot integrity |
| Browser and accessibility | `npm run test:browser` | Desktop/mobile Playwright and Axe |
| Real CI result | [Validate and Deploy CRYO Profile](https://github.com/Pierreg99/Pierreg99-Profile-Page/actions/workflows/deploy-pages.yml) | Actual run status, not decorative claims |

Only real checks justify a green status. / Nur tatsächlich bestandene Prüfungen begründen einen grünen Status.

## Scope and Limitations

- Public project counts are synchronized snapshots. GitHub primary-language labels are per repository, not lines of code or proficiency measurements.
- A dependency declaration does not prove deployment. Local symbols are original artwork, not official logos.
- Private repository names are never enumerated on the public page; only a preserved aggregate may be shown.
- Historical benchmarks and visual concept artwork are not independent performance certification.
- Public source access is not a substitute for checking licensing and third-party reuse conditions.

**DE:** Das Ziel ist eine zugängliche, glaubwürdige Dokumentation mit überprüfbaren Quellnachweisen.  
**EN:** The goal is an accessible, credible portfolio that makes evidence and uncertainty visible.
